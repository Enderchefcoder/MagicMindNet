MagicMindNet

Train real models. Load the Hub. Serve OpenAI-compatible APIs.

A beginner-friendly Python package powered by a from-scratch Rust core — transformers, classifiers, diffusion, GGUF, and eval harness in one install.

pip install magicmindnet See benchmarks

One install path

Published on PyPI as magicmindnet. Optional hub extras pull transformers / diffusers when you need remote models.

Production

pip install magicmindnet

# optional Hub backends
pip install "magicmindnet[hub]"

python -c "import magicmindnet as ai; print(ai.__version__)"
mmn-eval smoke
mmn-serve --help

From source (contributors)

git clone https://github.com/Enderchefcoder/MagicMindNet
cd MagicMindNet
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
maturin develop --release
bash scripts/verify_gate.sh
